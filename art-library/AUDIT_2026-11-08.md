# Art library pre-integration audit — 2026-11-08

## Scope
Repository inventory, source references, visual-preview source, game asset paths, automated smoke coverage and licensing documentation. This is **not** a completed manual visual QA or gameplay certification.

## Confirmed
- Four library documents exist and link to existing assets.
- Woodland atlas, four firefly frames, approved cottage exterior PNG, SVG interior and woodland preview are present in repository.
- Main game references the woodland atlas and approved cottage PNG; it does not reference the SVG by filename.
- Main game contains camera exploration/follow controls, save export/import, navigation and indoor state.
- The preview is a separate 640×400 HTML canvas experiment, **not** a game-integrated tileset.
- Third-party ArtStation artwork is not included in the asset library. Reuse rights are not verified.
- A previous Chromium smoke run passed for commit b49e4ab. This is not proof of pixel-perfect visuals or every interaction.

## Discrepancies and risks
1. The older cottage audit describes alpha.57 and an SVG as the published implementation, while current index.html loads `assets/cottage_approved_640x400.png`. Treat older audit as historical.
2. The woodland preview draws trees using smooth canvas arcs despite disabled image smoothing. This is a **style study**, not production-grade pixel tiles.
3. The preview's interior is a simplified procedural mock-up, not the approved game interior.
4. Library manifest lacks verified authorship, licensing and collision/occlusion metadata.
5. Existing source smoke tests primarily assert code patterns. Real movement, occlusion, camera transitions, and visuals still need manual/device testing.
6. The current source's visible version is v3.0.0-alpha.89; deployment freshness must be checked independently.

## Added protections
- `tests/art-library.test.mjs`: checks file presence, PNG header dimensions, reference documentation, preview structure and critical game controls.
- Browser smoke workflow runs the new asset tests before launching Chromium.
- Workflow outcome for commit d5f1e98 must be reviewed before declaring the validation passed.

## Required manual acceptance
1. Inspect the woodland preview and live game side-by-side at native 640×400 scale and on Android.
2. Confirm cottage entrance/exit, camera follow, camera explore, no camera lock at the cottage, and Spriglet's indoor/outdoor scale.
3. Verify path accessibility, canopy occlusion, tree collision, pond bank, nighttime fireflies, save export/import and restore.
4. Record screenshots and any issues; keep new woodland art out of the main game until accepted.
5. Resolve provenance for every production asset and keep ArtStation material reference-only absent permission.

## Release decision
**HOLD** on main-game art integration pending new workflow result and manual visual/gameplay verification. No gameplay rendering or save-schema changes were made in this audit.
