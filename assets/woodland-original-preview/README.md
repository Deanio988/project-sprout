# Original Project Sprout woodland assets

Restored from `Project_Sprout_original_woodland_assets.zip` (2026-11-04). All artwork is original geometric pixel art, not copied or traced from Nintendo assets.

- `sprites/woodland_tiles_32px.png`: 256×128 RGBA atlas; 8 columns × 4 rows of 32×32 tiles.
- `sprites/firefly_0.png` through `sprites/firefly_3.png`: four 32×32 RGBA animation frames.

The atlas is a starter kit, not a complete woodland scene. The existing game terrain and pathfinding remain in place while tiles are assessed individually. The firefly frames are loaded for nighttime ambience with a fallback if assets fail to load.

Original ZIP contained a standalone `index.html` preview and `README.md`. The preview is archived under `assets/woodland-original-preview/index.html` to avoid replacing the game's root index.
